# Внешняя проверка сайтов Fattakhov HR Agency

Раз в 5 минут GitHub Actions проверяет лендинг, кабинет CRM, фоновые задачи и платформу студентов,
а также срок сертификатов, и пишет в Telegram при падении и восстановлении. Раз в сутки в 9:00 МСК
приходит сводка: если её нет, сломан сам мониторинг. Работает независимо от серверов Selectel.

Секреты репозитория: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID. Если 60 дней не будет активности в репозитории,
GitHub отключит расписание: раз в пару месяцев заходите во вкладку Actions и включайте при необходимости.
